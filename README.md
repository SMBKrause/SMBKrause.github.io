# SMB Krause Lab website

Static site for https://smbkrause.github.io/. The files are intended for the GitHub Pages publishing root of the `main` branch. Edit the HTML, CSS, JavaScript, and assets directly; there is no build step. The prior site is preserved in the `backup-before-2026-redesign` branch.

The public CV PDF is a short professional summary. The contact address is assembled by JavaScript after a click, which discourages simple harvesting but cannot prevent determined scraping.
